## Жобаның мақсаты

Кампусқа күнделікті қатынайтын адамдарға бағыты мен сабақ кестесіне сай жолсерік табуды жеңілдету. Жоба аясында сапар жариялаудан бастап жолаушының өтінімін растауға дейінгі процесті қамтитын Android қосымшасын әзірлеу жоспарланған.

## Негізгі функциялар

- **Тіркелу және кіру:** пайдаланушы жеке аккаунтын ашады.
- **Сапар жариялау:** жүргізуші шығу орнын, баратын кампусын, уақытын және бос орын санын көрсетеді.
- **Сапар іздеу:** жолаушы бағыт пен уақыт бойынша қолайлы сапарларды қарайды.
- **Өтінімді басқару:** жолаушы өтінім жібереді, ал жүргізуші оны қабылдайды немесе қабылдамайды. Қабылданған кезде бос орын саны азаяды.
- **Менің сапарларым:** пайдаланушы алдағы сапарларын, өтінімдерінің күйін және өткен сапарлар тарихын көреді.

## Жүйе архитектурасы

**Android қосымшасы ↔ Retrofit ↔ Laravel REST API ↔ MySQL**

Android қосымшасы пайдаланушының сұрауын Retrofit арқылы серверге жібереді. Laravel өтінімді қабылдау кезінде бос орын бар-жоғын тексереді және нәтижені MySQL дерекқорына сақтайды. Мобильді қосымша серверден жаңартылған сапар деректерін алады.

## Жобалау үлгілері — Design Patterns

| Топ | Үлгі | Жоспарланған қолданылуы |
|---|---|---|
| Creational | Singleton | Android қосымшасында Retrofit клиентінің бір данасын ортақ пайдалану |
| Creational | Builder | Бағыт, уақыт және бос орын саны бойынша іздеу сұрауын құрастыру |
| Structural | Adapter | Сапар деректерін Android-тағы RecyclerView тізіміне бейімдеу |
| Behavioral | Observer | Өтінім күйі өзгергенде экрандағы ақпаратты жаңарту |
| Behavioral | Strategy | Сапарларды шығу уақыты немесе бос орын саны бойынша сұрыптау тәсілін ауыстыру |
